## 进入英文模式

- **macOS**：`Caps Lock` 亮起为英文模式，熄灭回到中文。
  想让 `Caps Lock` 像系统拼音那样在青简与「ABC」之间切换输入法，在「系统设置 → 键盘 → 文本输入 → 编辑」里打开用 Caps Lock 切换「ABC」的选项：
  轻按 `Caps Lock` 切换输入法，按住仍是大写锁定；这时青简自己的英文模式就用不到了。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」。
  反向同样有效：点击任务栏的「中 / 英」图标，青简随之切换（悬浮状态条一并更新）。
  中英模式**所有应用共用一份**：在一个应用里切到英文，切到别的应用、新打开的应用也是英文（与搜狗输入法一致）。
  右键这个图标弹出菜单：切中文 / 英文、全角标点、显示或隐藏悬浮状态条、打开设置。
  `Caps Lock` 在 Windows 上只控制大小写：亮起时无论中英模式均直接输出大写英文字母（与微软拼音一致）。英文模式下 `Shift` + 字母也直接输出大写；
  中文模式下 `Shift` + 字母缺省是临时打英文：拼音先上屏，这个大写字母原样交给应用；「设置 → 通用」可改成进拼音缓冲区参与匹配（见[按键](../getting-started/keys.md)）。

### 改掉或关掉中 / 英切换（Windows）

打字时误触 `Shift` 会切到英文、打断输入，可以在「设置 → 通用」里调整（配置 `[shortcut] switch_mode`，如 `["shift", "control"]`）。
下面几个键勾上哪个就能用哪个，可以多选：

| 选项 | 行为 |
|---|---|
| 单击 Shift | 缺省勾上，与微软拼音一致 |
| 单击 Ctrl | 不容易误触；Ctrl 在其他组合键里的作用不受影响 |
| Ctrl + Alt + Space | 组合键，最不容易误触 |

一个都不勾时键盘不再切中英，只能用任务栏 / 悬浮状态条上的「中」「英」按钮。
`Ctrl + Space` 不在其中：它是 Windows 自带的「输入法/非输入法切换」，青简跟着它切中英（与微软拼音一致），不用勾、一直可用。
装了英文键盘或别的输入法时，Windows 可能改用它直接切到别的输入法，这由系统决定；不想要这条系统热键，到「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。

如果习惯中英文用两个不同的输入法，可以关掉整个**内置英文模式**（同一页，配置 `[general] english_mode`）：
关掉后青简固定中文，切换键与状态栏按钮都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法；
语言栏上的「中 / 英」图标也不再出现。

两项都是**改完立刻生效**：输入法进程会盯着配置文件，变更后一秒内重新读取。

## 悬浮状态条（Windows）

任务栏的「中 / 英」不易察觉时，可另开一条**桌面上的悬浮状态条**：「设置 → 候选窗口」打开「悬浮状态条」。它有三格：

| 格 | 显示 | 点击 |
| --- | --- | --- |
| `中` / `注` / `英` | 当前模式（选了大千注音时显示「注」；双拼、五笔这类非全拼方案显示为「中 · 小鹤双拼」） | 切换中 / 英，与单击切换键相同；关掉内置英文模式后这一格固定「中」，点了也不切 |
| `，。` / `,.` | 当前模式下标点是否转为全角。中英各记一份，缺省中文全角、英文半角，切换模式时随之切换 | 切换当前模式的全角 / 半角 |
| ⚙ | | 打开设置 |

按住拖动可移到屏幕任意位置，位置会被记住；外观随系统的深浅色与缩放。
它只在当前输入法为青简时显示：切换到微软拼音等其他输入法时收起，切回后再次出现；关闭某个应用不影响它。它与任务栏图标并存。
前台是全屏应用（游戏、全屏看视频、演示）时自动收起，退出全屏后回来。也可以在任务栏「中 / 英」图标的右键菜单里随时显示或隐藏它。

## 行为

英文模式下输入字母时，候选窗口给出英文词的补全与拼写纠正：`recieve` → receive，`seperate` → separate。
字母缺省小写，按住 `Shift` 输出大写。

选词与中文模式一致：`Space` 选高亮候选（词上屏后空格照常输入），数字键选当前页第 N 个（没有第 N 个时数字接进单词，如 `foo1`），翻页键翻页，`↑` / `↓` 移动高亮，`Tab` 同样选高亮项。
**`Enter` 与标点将所敲字母原样上屏**：`kubectl` 这类词表中没有的词按 `Enter` 即可原样输出；没有候选时 `Space` 也原样上屏。
带数字的标识符（`mp3`、`utf8`）先按 `Enter` 输出字母再敲数字；没有候选时数字直接接在字母后。

标点在 macOS 上一律半角；Windows 上缺省半角，需要全角时见上文悬浮状态条。

## 用拼音查英文

想不起某个英文单词时，可在英文模式下直接输入它的中文拼音，候选窗口给出对应的英文，选中后上屏英文。

- **直接输入**：所敲字母能完整读成两个及以上音节的拼音时（`kaifa`、`yinhang`），候选中出现这些中文词的英文，右侧标注中文与词性：
  `kaifa` → develop（v. 开发）、exploit（v. 开发）。英文单词本身的候选仍排在前面：`change` 先出 change 与几个补全，再出「嫦娥」对应的英文。
- **`;` 开头**：没在输入时先敲 `;`，之后所敲字母一律按拼音查英文，单个音节也可以查：`;fan` → meal、rice（饭）、turn over（翻）……
  `;` 后面紧跟的不是字母（空格、`Enter`、标点、方向键）时，输出 `;` 本身。

选词方式与英文候选相同：`Space`、数字键、`Tab`。上屏的英文记入个人词表，之后输入它的前几个字母即可补全；同一串拼音下选过的英文排在首位。
`Enter` 仍原样上屏所敲字母。

只查覆盖整串拼音的词，不翻译整句；释义表中没有的词查不到英文。
双拼与注音下不自动查（这两种方案的按键几乎都能读成音节），需用 `;` 开头。
不需要直接输入时的英文结果，或想把 `;` 换成别的符号（如 `` ` ``）、关掉 `;` 入口，在「高级」页打开配置文件，修改其中 `english_lookup` 两项，每一项均附说明。

## 记住用户的词

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记入个人词表，下次输入时排在首位。选过的英文候选同样记录。

中文模式下 `key`、`id` 这类末尾落单一个字母、既像英文词又可读成拼音的输入，若常选中文词（如「客一」「以的」），中文词排在前面，英文词退后；
勾选「中文候选排在英文词前面」后中文词一律在前。

## 关闭

- 全局：「偏好设置 → 通用」（Windows：「设置 → 通用」）取消「英文模式给候选」。关闭后为纯直通，与未使用输入法时一致。
- 按应用：终端与代码编辑器中缺省不给候选，以免遮挡应用自身的补全或占用 `Tab` 键。
  macOS 的名单包括 Terminal、iTerm、Warp、Ghostty、VS Code、Cursor、Zed、JetBrains 系列、Xcode 等；
  Windows 的名单包括命令提示符、PowerShell、Windows Terminal、VS Code、Cursor、JetBrains 系列、Visual Studio 等。
  「通用」页有一个勾选框控制此名单。需要增减具体应用时，在「高级」页打开配置文件，修改其中 apps 一段，每一项均附说明。

## 与中文模式的关系

中文模式下整段输入为英文词时同样直接给出英文候选（`hello` 先英文再拼音，勾选「中文候选排在英文词前面」后英文排第二），拼音不成立时还会补全前缀（`compa` → company）。
无需切换到英文模式，见 [快捷输入](shortcuts.md)。
